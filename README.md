## ⚡ What Is This?

Most portfolios ask you to scroll.

This one asks you to **enter the lab**.

**GUNA // ENGINEERING SYSTEM** is an experimental interactive 3D portfolio designed as a futuristic personal engineering workstation.

Instead of presenting projects as ordinary cards and sections, the portfolio turns the entire interface into a spatial environment containing:

- 🤖 An interactive robotic manipulator
- 🔬 Electronics and embedded-systems workstations
- ⚙️ Robotics and calibration equipment
- 🧠 Engineering projects and experiments
- ♟️ Interactive games and simulations
- 🛰️ Spatial information systems
- 🖥️ Holographic-style interfaces
- 🌐 Portfolio, social and project modules
- 🎛️ Real-time 3D interaction

The goal is simple:

> **Make the portfolio itself demonstrate the way I think about engineering.**
